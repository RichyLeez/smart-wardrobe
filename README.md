# 智能衣橱（网页版）

拍照录入自己的衣服，结合身材数据和当天天气，每天用本地规则生成 3 套穿搭建议，不调用任何 AI 服务。

日常使用：打开 **https://richyleez.github.io/smart-wardrobe/** 。手机上建议在 Safari 里点「分享 → 添加到主屏幕」，之后像 App 一样从桌面打开，断网也能用。

数据保存在你自己的浏览器里，不会上传到任何服务器。手机和电脑各存一份，要在两边之间同步，用「设置 → 导出完整备份 / 从备份恢复」。

## 能做什么

- **录入**：拍照或选相册 → 本地智能去背（背景有花纹、地板缝、杂物也能处理；哪里不对就大致涂一笔「擦除」或「恢复」，松手后自动贴合边缘；纯色背景也可以用「按颜色」方式）→ 自动识别主色 → 点选子类后自动填好保暖度、季节、场合、风格、版型、长度、腰线。
- **衣架**：挂在衣架上拍也可以。去背后会自动认出领口上方的挂钩和伸出肩膀外的横杆并去掉；如果去掉的其实是衣服本身（比如挂脖带子），关掉「去掉衣架」开关就会保留。
- **正反两面**：每件可以再拍一张背面（把衣服左右翻过来平铺），人台转到背面和 3D 展示时使用；没拍背面的单品，背面用正面照片代替。
- **吊牌识别**：拍吊牌或洗标（也可以粘贴 iPhone 实况文本拷贝的文字），自动读出品牌、货号、号型、成分、执行标准和版型字样；号型和你的身材对比，告诉你这件偏大还是偏小，并换算成你穿上的实际版型。识别在本机完成，照片不上传。
- **分类**：衣橱和试搭里按颜色、品牌、面料、长短、版型、季节、场合、风格、保暖度筛选，或按这些维度分组浏览。
- **今日推荐**：输入气温（加减 1 度，或按天气预报填最高/最低气温）和场合，给出 3 套搭配，每套显示在按你身材比例生成的人台上，并附卷尺评分和理由。
  - 「换一件」：点下方任意单品，按换上后的整套得分列出替代品。
  - 「就穿这套」：记为今天的穿搭，之后推荐会自动轮换。
  - 「不喜欢」：这一套不再出现，相关组合降低优先级。
  - 「换一批」：排除已看过的组合，重新挑选。
- **穿法**：上衣可以「塞进裤腰」（配半身裙时是「塞进裙腰」），外套可以「敞开」。推荐会自己判断怎么穿更好（例如想显腿长时把长款上衣塞进去，不太冷时外套敞开），推荐、试搭和这件怎么搭里都能点开关改；人台和 3D 上，塞进去的上衣在腰头处截断，敞开的外套把合上拍的照片从中线拉开、露出里面的衣服。没拉拉链拍的外套，录入时打开「照片里是敞开的」，人台上就一直敞开显示。套装和穿搭记录会保存穿法。
- **试搭**：手动挑单品放上人台，拖动和缩放微调，引擎即时打分；可以切到背面看；可存为套装或记为今天。
- **3D 查看**：推荐方案、试搭和穿搭记录都能点「3D」。人台按你的身材数据生成，衣服用你拍的正面、背面照片包裹，袖子会转到手臂上，外套会罩住里面的衣服；拖动 360° 转动，双指缩放，也可以一键看正面、侧面、背面或自动旋转。这是看配色和层次的示意，不是真实布料的垂坠模拟。
- **记录**：月历、上身照片、穿着次数、穿过的单品占比、超过 30 天没穿的单品。
- **身材数据**：只要身高和体重（选上性别更准），肩宽、三围、腿长按 GB/T 1335 中间体比例估算；量过的尺寸可以展开填进去，填了就用实测值。身材建议只根据实测尺寸给出。
- **简化图形**：人台和 3D 上的衣服默认显示成"插画"——按照片里的颜色块重新画一遍，平铺时的褶皱、阴影、反光都去掉，条纹、印花、拼色保留。设置和 3D 页面里可以切回照片。
- **智能搭配**：每套按配色、天气、场合、风格、面料、身材、轮换、偏好 8 项打分。面料从吊牌成分或子类推断（棉、麻、真丝、羊毛、针织、牛仔、西装面料、皮革……），会看透气与保暖、质感对比、正式程度、牛仔叠穿、皮具呼应；配色会识别配色方式（中性色 + 点缀、同色系、邻近色、对比色）并画出色板，还会看鞋包与衣服的颜色呼应、花纹是否打架、从花纹里取色、上下版型松紧。
- **这件怎么搭**：在衣橱里打开任意单品，点「这件怎么搭」，按今天的气温和场合给出包含这件的几套搭配，可以直接「就穿这套」或带到试搭里调整。
- **设置**：身材数据、自动建议的搭配目标（可开关）、人台显示方式、整库 ZIP 备份与恢复、示例衣橱。

## 怎么运行

### 日常：打开网站

https://richyleez.github.io/smart-wardrobe/ ——手机和电脑都能直接打开。可以定位获取天气，也可以手动填气温。

更新网站：

```bash
npm run build
npm run deploy:pages   # 把 dist/ 推送到 gh-pages 分支，1 分钟左右生效
```

### claude.ai 发布版（可选）

`dist/artifact.html` 是发布到 claude.ai 的版本，数据存在 Claude 账号下、多设备自动同步。需要设备能访问 claudeusercontent.com，目前的网络环境下打不开，暂不作为日常入口。

### 离线或不登录：直接打开单文件版

用电脑上的 Chrome / Edge / Safari 打开 `dist/智能衣橱-单文件版.html` 即可使用。这种方式数据保存在这个浏览器里，和发布页面的云端数据互不相通，可以用「导出备份 → 从备份恢复」搬过去。

### 开发模式（电脑 + 同一 Wi-Fi 下的手机）

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

终端会显示两个地址：电脑用 `http://localhost:5173`，手机连同一个 Wi-Fi 后访问 `http://电脑IP:5173`。

手机通过局域网 http 访问时，拍照录入可以正常使用，但浏览器不允许定位，需要手动输入气温，也无法离线缓存页面。

### 部署到自己的网站（可选）

如果想要自动获取天气和离线使用，可以运行 `npm run build`，把 `dist/` 目录上传到任意支持 HTTPS 的静态网站托管服务，然后在 iPhone 的 Safari 里打开网址，点「分享 → 添加到主屏幕」。从主屏幕打开时：

- 可以定位获取天气；
- 断网也能打开和使用（天气除外）；
- 数据保存在这个主屏幕应用里，和 Safari 里打开的是两份独立的数据。

这种方式数据保存在本机，**请定期在「设置 → 导出完整备份」导出 ZIP**。清除浏览器数据、删除主屏幕应用或更换手机都会丢失本地数据，只能用备份恢复。

## 拍照建议

- 衣物平铺，完整入镜，四周留一点空白。
- 深色衣物用浅色背景，浅色衣物用深色背景，背景越纯越好。
- 光线均匀，避免强烈阴影。
- 上衣和外套把袖子摆开，换装时更像穿在身上。
- 挂在衣架上拍也行，衣架会自动去掉；背景尽量是纯色的墙或门。
- 外套最好拉上拉链、扣好扣子拍：这样搭配时可以选敞开或合上。没拉拉链拍的，中间露出的里衬用「擦除」涂掉，再打开「照片里是敞开的」。
- 拍背面时像翻书一样左右翻面，领口仍然朝上，摆成和正面差不多的形状。

## 推荐规则

每套搭配按 8 项打分后加权，满分 100：

| 项目 | 权重 | 看什么 |
| --- | --- | --- |
| 配色 | 24% | 中性色与重点色的数量、色相关系、上下装深浅对比；鞋包等配件与衣服的颜色呼应；花纹：条纹配格纹、两件印花会提醒，纯色单品取花纹里的颜色加分 |
| 天气 | 20% | 上身总保暖度是否落在当天气温的合适区间、是否需要外套、短裤凉鞋靴子是否合时宜、雨天的鞋和浅色长裤 |
| 场合 | 14% | 主要单品是否标注了当前场合 |
| 风格 | 12% | 单品之间的风格兼容度（例如商务与运动冲突）；上下都宽松显得松垮、一松一紧更利落 |
| 面料 | 10% | 热天是否透气、冷天是否保暖；顺滑与粗纹理的质感对比；三件厚重面料、两件亮面面料、颜色接近的牛仔叠穿会提醒；面料正式程度是否一致、是否符合场合；皮鞋皮带皮包同色加分 |
| 身材 | 9% | 你开启的搭配目标：拉长腿部、平衡上身、平衡下身、突出腰线 |
| 轮换 | 6% | 最近 2 天穿过的降低优先级，超过 21 天没穿或从没穿过的提高优先级 |
| 偏好 | 5% | 你点过「就穿这套」或「不喜欢」的组合 |

面料：有吊牌成分时按主要纤维判断，没有时按子类的常见面料估计（例如西裤按西装面料、T 恤按棉质针织、毛衣按针织），规则在 `core/fabric.ts`。

生成过程：先按气温、季节和场合筛掉明显不合适的单品 → 枚举上下装与连衣裙 → 叠加外套 → 为每套挑最合适的鞋 → 只在能提高得分时加入包、腰带、围巾等配饰 → 选出彼此差异较大的 3 套。符合条件的单品不足时，会依次放宽季节和场合条件，并在页面上说明。

穿法：每套会试一遍"上衣塞不塞、外套敞不敞"的组合，取得分最高的一种（`core/styling.ts`、`recommend.ts` 的 `withBestStyling`）。塞进去会露出腰线，有拉长腿部、突出腰线的加分，上下都宽松时不再提醒松垮；外套敞开时保暖按 6 成计算，8°C 以下提醒拉上，敞开的竖向线条对拉长身形、平衡上身有加分，配色计算里内搭露出的面积也更大。短款上衣不参与塞进去，没有下装时也不塞。

身材相关的规则来自常见穿搭经验，不是精确科学，可以在设置里逐项开关。

## 目录结构

```
src/
  core/        纯逻辑，不依赖浏览器，可直接移植到微信小程序
    types.ts       数据类型
    catalog.ts     类别、子类默认值、中文标签、风格兼容表
    color.ts       Lab 色彩转换、主色提取、中文色名、中性色判断
    fabric.ts      面料推断与面料属性（质感、厚重、正式程度、透气、保暖）
    stylize.ts     简化图形：色块归并去褶皱、平滑轮廓、统一明暗与描边
    background.ts  按颜色去背（背景估计、连通区域生长、去碎块、羽化、手动笔刷）
    smartcut.ts    智能去背（颜色模型 + 图割，笔刷作为确定的衣物/背景）
    hanger.ts      识别衣架（形态学开运算分出细的部分，按挂钩、横杆的位置和颜色判断）
    maxflow.ts     网格图最大流（Boykov–Kolmogorov 算法）
    body.ts        身材校验与比例、搭配目标建议、人台几何、衣物摆放、正面/背面视图
    body3d.ts      3D 人台：按身材数据生成的分段截面与网格
    garment3d.ts   3D 衣物：照片包裹的外壳、袖子圆筒、外层包住里层、鞋
    weather.ts     气温分档与保暖需求
    recommend.ts   推荐引擎（打分、候选生成、换一件、偏好更新）
    styling.ts     穿法：能否塞进去 / 敞开、人台叠放顺序、把合上的外套照片拉开
    stats.ts       穿着次数、闲置统计、日期工具
    backup.ts      备份格式与校验
  storage/     存储：db.ts 入口；cloud.ts 云端（发布页面）；idb.ts 本机；memory.ts 兜底；backup.ts ZIP 备份
  ui/          React 界面（页面、组件、状态）
tests/         单元测试（含云端存储的模拟环境 fake-cloud.ts）
scripts/       esbuild 构建脚本、端到端测试（云端模式、吊牌识别、去背与 3D、智能搭配、穿法与衣架）
public/        图标、manifest、离线缓存脚本
```

## 常用命令

```bash
npm test          # 运行单元测试
npm run typecheck # TypeScript 类型检查
npm run build     # 生成 dist/（含 artifact.html）
npm run e2e:cloud # 模拟发布环境，在无头浏览器里走一遍完整流程（需先 build）
npm run e2e:tag   # 吊牌识别与分类筛选
npm run e2e:3d    # 智能去背、正反两面照片、人台背面和 3D 查看
npm run e2e:smart # 只填身高体重、简化图形、色板与面料评分、这件怎么搭
npm run e2e:styling # 塞进去、外套敞开、套装和记录保存穿法、衣架识别
```
